# Real-Time Patient Fall Detection Model

> **Computer Vision & Pose-Based Safety Monitoring for Elderly & High-Risk Patients · MedGuardAI Subsystem**

## Overview
Automated fall-detection module designed for smart hospital rooms and home-care monitoring within the **[MedGuardAI](https://github.com/HANIDEVINF/MED-Guard-AI.)** ecosystem. Detects sudden posture collapse, bounding-box aspect-ratio inversion, and post-fall immobility to dispatch immediate emergency notifications to caregivers and assigned clinicians.
